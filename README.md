# GoIT Markup Homework #1

This project is the first homework assignment within the GoIT Full Stack Developer program. It focuses on building foundational HTML markup structure without CSS styling, following strict semantic and structural guidelines.

## 🚀 Live Demo
- [View Live Page](https://meryemozkan1.github.io/goit-markup-hw-01/)

## 🛠️ Technologies & Tools Used
- **HTML5:** Semantic markup structure (`<header>`, `<main>`, `<footer>`, `<nav>`, etc.)
- **Prettier:** Code formatting
- **Git & GitHub:** Version control and GitHub Pages deployment

## 📋 Project Requirements & Implementation Details
- Main HTML file is named `index.html`.
- All assets are organized within an `images/` directory.
- Semantic HTML tags are used according to content accessibility standards.
- Text content and bitmap images were sourced directly from the Figma layout guidelines.
- `alt` attributes and proper dimensions (`width`) are applied to images.
